# claude-kit

Kit universal de método de trabalho com o Claude: núcleo (`CLAUDE.md`), skills, agentes, comandos e
hooks opcionais, prontos para qualquer máquina. Para aplicar, mande para a IA: "aplique o kit de
`<link deste repositório>`" — ela lê `LEIA-PRIMEIRO.md` e remonta tudo sozinha, sem script de
instalação.

Sem Claude Code (chat do claude.ai): cole o conteúdo de `nucleo/preferencias-claude-ai.md` nas
Preferências.

Veja `VERSAO` e `CHANGELOG.md` para o histórico. Público e sem segredo — módulos específicos de
máquina (ex. `modulos/vps`) ficam inativos até serem pedidos.
